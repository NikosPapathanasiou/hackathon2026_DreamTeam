Specific Tasks:

// API Endpoints to build:
POST   /api/auth/register          // Register parent account
POST   /api/auth/login             // Login
POST   /api/children                // Create child account
GET    /api/children/:id            // Get child details
POST   /api/transactions            // Create transaction
GET    /api/transactions/:childId   // Get transaction history
POST   /api/budgets                 // Set budget/limit
GET    /api/budgets/:childId        // Get budgets
PATCH  /api/transactions/:id/approve // Parent approve transaction
GET    /api/balance/:childId        // Get current balance
Database Schema:
users (parents/guardians)
children (child accounts)
transactions (spending records)
budgets (spending limits & goals)
educational_progress (learning module completion)
Tech Stack:
Backend: Node.js + Express

Auth: JWT or Passport.js
